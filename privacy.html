DeskMemo 개인정보처리방침

최종 수정일: 2026-11-25

1. 사용하는 정보

DeskMemo는 Google 캘린더 권한(calendar.events)만 사용합니다. 이 권한으로 사용자가 작성한 메모를 사용자 본인의 Google 캘린더에 일정으로 만들고, 고치고, 지웁니다. DeskMemo가 만든 일정 외의 캘린더 내용은 읽거나 바꾸지 않습니다.

2. 정보의 저장

메모와 로그인 정보(인증 토큰)는 사용자 PC에만 저장됩니다. 개발자나 다른 서버로 전송·수집·보관하지 않습니다.

3. 제3자 제공

사용자 정보를 제3자에게 판매하거나 제공하지 않으며, 광고에 사용하지 않습니다.

4. Google API 데이터 사용

DeskMemo가 Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 해제

언제든지 Google 계정 → 서드파티 액세스에서 DeskMemo의 접근 권한을 삭제할 수 있으며, PC의 DeskMemo 폴더를 지우면 저장된 정보도 모두 삭제됩니다.
